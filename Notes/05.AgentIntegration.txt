WHAT EACH FILE CHANGES IN COPILOT'S ANSWERS
--------------------------------------------------------------------------------
  File                       Effect in this repo
  -------------------------  --------------------------------------------------
  copilot-instructions.md    Forces the goal skill to be read, so answers stay on target instead of generic.
  goal-of-this-repo          Keeps changes simple, POM-based, interview-ready. Example: BasePage kept thin, no unused helpers.
  about-me                   Pitches depth for a 3.5-year SDET going for Senior SDET / SDET-2 roles; notes are crisp.
  framework-must-haves       Gives a checklist to measure progress against (auth reuse, fixtures, CI/CD, Docker, reports...).
